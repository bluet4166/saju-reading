# 사주 대시보드 · Saju Dashboard

사주팔자와 오행 분포를 기준으로 **5년 단위 운세 흐름**과 **연애 · 사업 · 금전 · 건강** 네 갈래를
시각화한 정적 웹사이트입니다.

- 빌드 도구 없음. `index.html` + `style.css` + `app.js` + `data.js` 만으로 동작합니다.
- 차트는 외부 라이브러리 없이 SVG 로 직접 그립니다.
- 배포: GitHub Pages

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 문서 구조 |
| `style.css` | 다크 잉크 + 골드 테마, 반응형, 인쇄/모션 접근성 대응 |
| `app.js` | 데이터 바인딩, 5년 단위 막대 차트 · 연도별 꺾은선 차트, 탭, 툴팁 |
| `data.js` | **자동 생성 파일** (직접 수정 금지) |
| `tools/generate-data.mjs` | 사주 계산 → `data.js` 생성 |
| `tools/serve.mjs` | 로컬 미리보기 서버 |

## 데이터 재생성

사주 계산은 [`saju-fortune`](https://www.npmjs.com/package/saju-fortune) 패키지로 로컬에서 수행합니다.
(MCP 서버를 띄우지 않습니다.)

```bash
npm install -g saju-fortune
# Windows PowerShell
$env:NODE_PATH = (npm root -g)
node tools/generate-data.mjs
```

입력 정보(생년월일·시각·성별)는 `tools/generate-data.mjs` 상단의 `SUBJECT` / `INPUT` 상수에서 바꿉니다.
음력 생일은 검증된 만세력으로 양력 변환한 뒤 `calendar: "solar"` 로 넣습니다.

## 로컬 미리보기

```bash
node tools/serve.mjs 4173
# http://127.0.0.1:4173/
```

## 점수 산출 모델

```
연도점수 = 50 + (천간값 × w + 지지값 × 0.8 × w) × 1.6 + 대운보정
5년 구간 점수 = 구간 내 연도 점수의 평균
```

- **오행 기본값**: 용신 +10, 희신 +8, 재성 +2, 식상 과다 −2, 구신 −5
- **주제별 가중치 `w`**: 연애(화 1.3) · 사업(금 1.2) · 금전(금 1.5) · 건강(수 1.3) 등
- **대운 보정**: 대운 간지가 용신·희신이면 +3, 구신이면 −2
- 산출 근거는 사이트의 **「산출 방식과 한계」** 섹션에도 그대로 표기됩니다.

## 면책

이 사이트는 전통 해석에 기반한 참고 자료입니다. 점수는 길흉의 확정이 아니라 흐름을 비교하기 위한
상대 지표이며, 의료·투자·법률 판단을 대신하지 않습니다.
